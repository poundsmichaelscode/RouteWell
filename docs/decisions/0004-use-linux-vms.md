# ADR-004: Use Ubuntu Linux Virtual Machines

## Status

Accepted

## Decision

Use Ubuntu Linux VMs for the web, application, and database tiers.

## Why

- Required by the capstone
- Supports the selected stack
- Provides practical Linux administration experience
- Demonstrates SSH, services, permissions, firewalls, patching, and logging

## Trade-Off

The project team is responsible for operating-system maintenance and hardening.
