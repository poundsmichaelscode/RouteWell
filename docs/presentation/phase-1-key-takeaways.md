# Key Takeaways

- Architecture begins with requirements, not resource creation.
- Flat networks provide inadequate isolation.
- Only approved entry points should be public.
- PostgreSQL should not require a public IP.
- Separate subnets support tier-specific controls.
- Backend authorization remains mandatory.
- Low-cost architecture can still support future scaling.
- Application Gateway requires a dedicated subnet.
- Security controls should overlap.
- Architecture decisions should document trade-offs.
