# Technology Justification

| Technology | Purpose | Justification |
|---|---|---|
| React | Frontend UI | Component-based and suitable for dashboards |
| Vite | Frontend tooling | Fast development server and efficient production builds |
| Tailwind CSS | Styling | Consistent responsive utility classes |
| Node.js | Backend runtime | Appropriate for REST APIs and asynchronous I/O |
| Express.js | API framework | Mature, flexible, and middleware-oriented |
| PostgreSQL | Relational database | Transactions, constraints, indexes, and strong relational integrity |
| JWT | Authentication | Supports stateless API authentication |
| Nginx | Web server and proxy | Serves static assets and proxies API requests |
| PM2 | Process supervision | Restarts and supervises the Node.js process |
| Ubuntu Linux | VM operating system | Stable, widely used, and appropriate for the stack |
| Azure VNet | Network boundary | Provides private IP communication and subnet segmentation |
| Azure NSG | Traffic filtering | Enforces source, destination, protocol, and port restrictions |
| Application Gateway | Public HTTP entry | Supports routing, health probes, TLS, and future scaling |
| Azure CLI | Cloud automation | Enables repeatable Azure provisioning |
| Bash | Linux automation | Automates configuration and deployment tasks |
| Git | Version control | Tracks source and infrastructure changes |
| GitHub | Collaboration and portfolio | Hosts the repository and future workflows |
| Swagger/OpenAPI | API documentation | Provides an interactive API contract |
| Mermaid | Diagrams as code | Allows architecture diagrams to be version controlled |
