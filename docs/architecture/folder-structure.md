## Folder Responsibilities

### frontend

Planned React, Vite, and Tailwind application. Frontend code must never contain database passwords, JWT signing secrets, SSH keys, or Azure credentials.

### backend

Planned Express REST API. It will contain authentication, authorization, validation, logging, error handling, Swagger documentation, and business modules.

### database

Planned PostgreSQL migrations, schema, seed data, and backup documentation.

### azure

Planned Azure CLI, parameter, policy, and infrastructure documentation.

### docs

Planning, architecture, networking, security, deployment, testing, troubleshooting, and presentation documents.

### scripts

Planned Azure, Linux, database, deployment, and testing automation.

### diagrams

Mermaid source files for architecture, data, and network diagrams.

### screenshots

Evidence captured throughout the capstone for final documentation and presentation.
