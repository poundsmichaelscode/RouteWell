# Screenshot checklist

Capture these images after the live stack passes its health checks:

1. Landing page in light mode.
2. Landing page in dark mode.
3. Operations dashboard.
4. Delivery list and tracking timeline.
5. Customer, driver, vehicle and route screens.
6. Reports export screen.
7. User administration.
8. System monitoring.
9. Swagger UI.
10. Successful GitHub Actions run.
11. Azure Application Gateway backend health.
12. Azure VNet/subnet and NSG overview.
13. Log Analytics query result.

Use synthetic seed data only. Redact subscription IDs, tenant IDs, IP addresses when appropriate, repository secrets, cookies and authorization headers.
